# 通用生成页面 UI 整改

2026-10-27。状态：通用 CRUD 生成资产已整改；验收证据与运行身份见 [结构化报告](core-evidence/generic-ui-alignment.json)。这是通用页面及食谱分类页的本轮交付，不代表所有未来 AI 页面自动符合视觉规范。

## 基准与实现

基准仍为显式模板的用户管理 index.vue、UserForm.vue、AddUser.vue 与 ConfirmDialog.vue。复用全局应用容器、pa-4 卡片、主题字体/颜色/圆角、Tabler 图标、outlined/comfortable 字段、secondary/compact 弹窗标题栏和模板分页常量。

`specforge/assets/BusinessPanel.vue` 是本轮修改的生成资产：

- 用 v-data-table-server 代替手写表格和另一套分页，显示加载、空态、服务端总数，页大小与页码发给原分页接口。忽略过期加载结果，避免快速切页时旧响应覆盖新数据。
- 通用接口最多100条；复用模板分页选项中的10/20/50/100，不提供不受接口支持的200/500。接口不支持排序，因此所有列关闭排序，并隐藏手机端无效的“排序方式”入口；没有新增假的查询或排序功能。
- 新增/编辑/详情统一800px弹窗，手机useDisplay().xs全屏；正文可滚动，取消/保存始终可达。
- 字段保持原规格、类型、默认值和表单范围。只校验允许填写的字段，明确提示必填、整数及最小值；复用setBackendErrors回填，取消时清理错误。布尔false不被误判为空。
- 详情按规格标签展示，同时保留可用数量、时间等接口附加信息。不会因重新排版丢弃原详情字段。
- 删除和业务状态操作直接复用模板ConfirmDialog；保留防重复执行、后端错误诊断、权限判断及原业务状态转换，不再使用window.confirm。
- 深色标签沿用上一阶段的on-surface对比度适配；错误和焦点颜色继续交给组件主题。

未修改模板主题、后端业务、认证权限、SQL或旧运行时。没有将全部模板模块改造成新的组件库。

分类页在1280×800、390×844与浅/深色条件下检查列表、编辑和错误态；详情、确认操作保存代表性截图。对照上一阶段同条件模板基准，沿用相同内容外壳和控件体系。手机列表使用Vuetify的字段标签布局，不是压缩桌面表格。
