# 旧方案已退役

决定日期：2026-10-28；用户明确要求不再保留旧方案。此决定替代原冻结兼容、等待旧调用方退出的约定。

当前仅维护specforge/，使用明确规格、显式模板和独立项目工作区。旧specforge-runtime、内置旧backend、旧skills及tests_compat从当前代码树移除；没有保留运行代理、兼容命令或自动回退。发布CI只测试当前核心。

退役前这些目录整体移到仓库外私有目录，包含未跟踪/忽略的旧runs、outputs、缓存和数据；未永久删除这些本地数据，未上传归档。私有归档位置在本机退役清单中记录。新核心已交付项目、外部状态目录、数据库及演示容器不受影响。Git历史、历史标签和验收JSON保留取证，历史文档明确标记不可执行。

外部OpenClaw/飞书旧生成入口必须明确拒绝，不再启动旧runner，也不把自然语言参数静默传给新CLI。通用清理脚本不再遍历SpecForge目录。重新接入外部系统时必须另行实现明确规格/模板/工作区/验收合同，本次不重建集成。

默认分支使用保留历史的正常合并切换到新核心，远端旧提交仍是祖先，不强推、不删除已发布标签。旧版远端新增内容经核对均属旧运行时/旧模板，在当前树不重新引入。

本版为0.2.0：这是主动取消旧接口兼容的破坏性变更。旧命令和自然语言入口不再可用，不能把历史测试结果作为当前支持范围。
