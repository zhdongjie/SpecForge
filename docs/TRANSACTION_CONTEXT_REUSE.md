# 第三轮复用：统一 JDBC 事务接入

2026-10-29，状态：已验证。完整输入身份、源码清单、交付包哈希与报告位置见 [证据](core-evidence/transaction-context.json)。

通用 CRUD 原先自行创建 DataSourceTransactionManager，食谱和工单分别获取平台管理器。统一注入模板 BusinessJdbcContext 后，三个入口都使用 MyBatis 的实际数据源和平台管理器；每个调用方获得独立 TransactionTemplate，不改变业务隔离级别、权限或锁顺序。模板缺少此能力时，生成前停止，不能等到交付包启动时报类缺失。

模板负责公共事务接入，SpecForge 负责生成绑定与能力检查，工单业务仍在独立私有仓库。没有新增工作流引擎或认证权限基础设施。模板能力说明见模板仓库 docs/template/data-transactions.md。
