# 食谱主流程 UI 整改结果

2026-10-27。状态：食谱主流程已整改并复验；通用 CRUD（包括分类管理）仍待下一阶段统一。不是整站全部页面已完成的声明。

## 基准和实施范围

列表依据模板 `frontend/src/pages/system/user/index.vue`；弹窗依据 `AddUser.vue`、`UserForm.vue`；危险操作直接复用 `components/ConfirmDialog.vue`。视觉权威仍是传入模板的 UI 指南和主题源码。

- `RecipePanel.vue`：沿用 pa-4 卡片和应用容器，查询改为 outlined/compact 与搜索/重置按钮；图文卡片用 Vuetify 网格、主题表面和默认圆角，移除独立宽度、渐变、颜色与字体体系。
- 发布/编辑采用 secondary/compact 标题栏、outlined/comfortable 字段、响应式网格；上传改为 v-file-input，仍调用原封面上传接口和文件引用流程。
- 表单使用 v-form 字段规则与模板 setBackendErrors 回填，校验名称、分类、食材、步骤及数字范围；取消清除表单错误，避免污染列表。当前采用 Vuetify rules 承载客户端校验，是对模板既有 fieldErrors 模式的业务组合，不另建校验库。
- 详情、驳回与删除确认统一弹窗、表面与操作层级；手机用 useDisplay().xs 全屏，长表单仅正文滚动，取消/保存固定可达。
- 空态分别解释无搜索结果、无收藏、无待审及无发布记录；只读用户不再被引导发布。
- `RecipeStats.vue` 统一卡片、标题、网格、主题字体与刷新按钮，补齐加载和错误状态。

业务差异保留：食谱使用图文卡片，食材与步骤是动态表单，不强行套后台表格。深色标签是一次明确的可读性适配：input-border 是弱边框色，不能兼作正文色；闲置标签改用 on-surface，错误/聚焦仍用组件语义色。模板源、认证权限、数据库与后端业务实现未变。
