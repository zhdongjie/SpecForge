# SpecForge v0.2.1：工作区硬性隔离

2026-10-29。为新版核心补齐工作区与源码/模板的执行边界。

- 六个CLI命令在解析输入及进入阶段前执行公共路径检查；直接调用生成、运行目录读取和打包函数也执行检查。
- 拒绝工作区与核心源码或显式模板相互包含；解析真实路径，禁止runs/releases通过符号链接或junction重定向。
- wheel安装保护实际包目录，允许同一虚拟环境内与包目录不相交的工作区；从源码树调用安装包时也检查源码边界。
- Windows包装入口在创建浏览器队列和启动辅助进程前预检；不提供绕过开关。
- 统一包内版本与安装元数据为0.2.1，修正原包内遗留0.1.0版本值。

核心109项测试通过；实际wheel安装、合法外部目录生成、非法路径拒绝及Windows包装预检通过。本机27个既有外部工作区通过路径检查且最新输入和报告可读取；仓库内没有待迁移的运行工作区，sandbox需求草稿原样保留。

本版不自动迁移或删除现有数据，不改变业务生成规则。当前工作区合同见docs/knowledge/contracts/workspace-release.md。食谱完整交付回归另行记录，不以本次路径回归替代业务和视觉验收。
