# D-006 只维护单一新核心

- 编号：D-006
- 状态：已采用，替代旧版冻结兼容
- 适用范围：SpecForge当前代码树、发布、外部旧生成入口
- 最近验证日期：2026-10-28
- 证据：[旧方案退役](../../LEGACY_RETIRED.md)

问题：并行保留旧运行时、旧后端与技能入口让仓库仍然庞大，并且外部调用可能继续绕开新版明确规格和完整验收合同。用户已明确取消旧方案。

采用：当前代码树只保留specforge/及其测试、样例和工具；移除旧runtime、backend、skills和兼容测试。旧本地目录连同运行数据整体移至仓库外私有归档，Git历史和验收报告保留。旧生成集成明确拒绝，不保留回退开关，不自动翻译自然语言参数。默认分支通过保留历史的正常合并收敛到当前核心。

代价：旧命令和旧外部集成不再可用；调用方需使用新版明确规格，或另行实现经验收的新适配器。历史记录中的兼容承诺不再生效。

重新评估：只有用户明确提出新需求时，才按新核心合同实现相应能力；不能为了兼容而整包恢复旧架构。数据取回与历史取证不等于恢复旧运行时。
