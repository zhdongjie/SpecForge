# D-005 显式应用扩展承载实际业务

- 编号：D-005
- 状态：已采用
- 适用范围：通用 CRUD / 借用能力无法表达的完整应用
- 最近验证日期：2026-10-24
- 实现：[显式注册表](../../../specforge/applications/__init__.py)
- 证据：[应用边界回归](../../../tests_core/test_recipe_application.py)

问题：食谱需要作者可编辑、公开浏览、明细保存、收藏与审核，不能把借用状态转换强行套入其中。

采用方案：规格用 application 明确选择版本管理的应用模块，模块校验固定存储合同、生成业务 API 与页面、提供必要 SQL 和权限；核心不根据项目名或字段猜测领域。普通规格不声明 application 时保持现有行为。

代价：该模块内的特定规则需要代码维护，不能声称仅调整任意 YAML 字段即可生成新的业务语义。所有新增业务边界必须有专属验收包。

重新评估条件：多个真实应用出现同样的作者审核或主从明细需求时，先比较真实案例，再提取通用合同；不提前把全部应用规则堆进 BusinessResource。
