# T-005 临时管理员密码必须满足模板合同

- 编号：T-005
- 状态：已解决
- 适用范围：admin-platform 首次初始化；SpecForge 独立交付验收工具
- 最近验证日期：2026-10-24
- 实现：[验收工具](../../../tools/verify-release.py)
- 证据：本轮独立交付报告，最终汇总见 [独立部署证据](../../core-evidence/release-delivery.json)

现象：首次独立交付验收容器启动后 API 返回非 JSON，第二次启动报告后端不健康。后端日志显示“首次初始化需要有效的管理员账号与密码环境变量”。

根因：新验收工具生成了 19 位临时密码，超过模板首次初始化允许的 8–16 位。启动健康检查曾短暂通过，不代表初始化成功。

处理：临时密码生成遵守模板已有的长度、大小写字母及数字要求；不修改认证和初始化基础设施。补充回归检查，读取工具产生的临时配置验证密码格式，测试输出不包含密码。

验证：修正后设备、原图书和字段变体使用全新数据卷执行独立部署 API / 浏览器验收。失败运行单独保留脱敏诊断，不覆盖成功报告，也不改写包内文件。
